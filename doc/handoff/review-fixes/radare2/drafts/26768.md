## New PR

**Title:** Keep the Thumb bit off data symbols in ARM ELF ##bin

Supersedes #26768.

In ARM ELF, bit 0 of a symbol value selects Thumb only on function symbols (AAELF32 5.5.3): STT_FUNC, STT_ARM_TFUNC (LOPROC) and STT_GNU_IFUNC. radare2 applied it to every symbol:
- `_set_arm_thumb_bits` cleared bit 0 on every symbol, so an odd data object was reported one byte low and as Thumb.
- `Elf_(get_bits)` counted every odd symbol, so one odd data object made a .so without mapping symbols bits 16.

Both now ask `is_arm_function_symbol`: FUNC, LOPROC, and LOOS when EI_OSABI is NONE, GNU or FreeBSD (type 10 = GNU_IFUNC there). vaddr and paddr are cleared independently, each only when valid. Before, a function with no paddr kept bit 0 in its vaddr, and a `$t` with no paddr got paddr 0xfffffffffffffffe.

Tests in `db/formats/elf/symbols` check only paddr, vaddr, type and name (`is,...,:csv`). Four of them are synthetic ELFs of 416-448 bytes, written to `malloc://` and opened with `oba 0` like the `relr` test. They can move to radare2-testbins.
- arm32 `msg.8676` stays at 0x69a2d.
- An odd OBJECT in an ET_DYN without mapping symbols gives bits 32 (master: 16).
- A Thumb IFUNC with st_value 0x59 and OSABI GNU is at 0x58. The same image under OSABI ARM (97), where 10 is not IFUNC, stays at 0x59 (master: 0x58).
- In a debug-file layout (NOBITS .text), a Thumb FUNC has vaddr 0x58 (master: 0x59) and `$t` has no paddr (master: 0xfffffffffffffffe).

`db/cmd/cmd_aafs` loses 2 functions: master moved `blanks` (0x677c7) and `_nl_category_name_idxs` (0x6af95) one byte down, leaving a 1-byte `obj.*` plus `fcn.000677c7` and `fcn.0006af95`.

r2r over `db/{anal,asm,cmd,esil,formats,io,json,tools}` (18703 tests) gives the same results as master, except that master fails `cmd_aafs` and four of the new `symbols` tests.

Not covered, shared with other formats: `handle_arm_hint` (`libr/core/cbin.c`) still adds a bits=16 hint at an odd data address (`ah`, used by `pd`), and `r_bin_get_vaddr` still rounds odd vaddrs in `*text*` sections of bits-16 files.

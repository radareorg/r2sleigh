## Blocking soundness defects

**B1. r2dec owns a second, unsound callee-reach reader.** The reader is `r2dec/src/binding_plan/rules.rs:840` `escaped_pointee_reach`.
- It ignores `scaled_by`, so the `a[5]` that `set(a, 5)` writes is missed.
- `?` at :970 drops a callsite whose transfer length is not a constant (`memset(buf, 0, n)`).
- It ignores `unplaced_reach`.
- `find_map` counts only the first callsite.
- An access with no range is skipped whenever any transfer exists.

**B1'. `FunctionSemanticSummary::argument_touch_reach` (`r2ssa/src/interproc/mod.rs:1375`) is itself unsound.**
- A second scaled access through the same argument overwrites the first.
- A constant span replaces a scaled one, so `p[0]` and `p[i]` reach only `p[0]`.

**B2. The frame-escape model has two disagreeing owners.**
- `interproc/dependence.rs:441` says one escaped frame address exposes the whole frame.
- r2dec `rules.rs:806` and `promote.rs` say reach only goes upward.

**B3. Spill tracking misses writes.** In `r2ssa/src/address.rs:455`, a store clears only the slots with the same root. These clear nothing:
- an overlapping store;
- a store through an unknown frame address;
- a call handed a frame address.

## The real defect behind B1-B3: four escape analyses

| # | Where | What escape means |
|---|---|---|
| 1 | `promote.rs:431-872` (raw IR, before SSA) | stored as value, non-Unique register, indexed; reach upward |
| 2 | `semantic/facts.rs:302` `escaping_addresses` + `shared.rs:1652` `evidenced_stack_roots` | syntactic: a direct call use or store of the root var |
| 3 | `semantic/private_objects.rs:5` `private_stack_objects` | forward walk through derived values; no reach |
| 4 | `r2dec/.../rules.rs:736` `frame_objects_with_escaped_address` + `escaped_pointee_reach` | boundary read or non-address use; reach from summaries |

`dependence.rs:441` reads #3 and turns it into whole-frame exposure.

Extents also have several owners:
- `callee_write_spans`, which combines callee reach with name-keyed `seed_for_callee_name` seeds;
- `evidenced_stack_roots`;
- `DeclaredStackSlots::containing`;
- `frame_gap_extent`, which is a guess;
- `accessed_object_storage`;
- r2types `canonicalize_param_home_stack_slots`.

Callee reach arrives through two channels:
- `machine_context.callee_argument_reach`, from r2engine's prepared callees;
- `report().interproc_summary_set()`.

The fix is P4's single `FramePartition` in r2ssa:
- objects with extents;
- MUST boundaries and MAY merges;
- escapes with their sites and a union reach (`Bytes` or `Frame`);
- managed (round-trip) slots;
- promotion.

Every list above then becomes a reader of it.
